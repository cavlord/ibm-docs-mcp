# Project Context & Documentation Rules (Ask Mode - Non-Obvious Only)

- **Mandatory MCP Answering**: Refer to `rules.md`. Always query the MCP server before answering questions and provide the official IBM documentation verification link.
- **PowerSC MCP Integration**: Queries regarding PowerSC (security profiles, commands, RTC, FIM, MFA, agent setup) should be resolved using the registered `ibm-docs-powersc` MCP tools (`search_powersc_docs`, `powersc_troubleshoot`, `powersc_command_reference`).
- **Core IBM i Topics**: Topics regarding core OS/400 operations (e.g. `WRKACTJOB`, `MSGW`, `WRKOBJLCK`, tape drives `TAPxxx`, BRMS) are system-level commands, distinct from PowerSC security modules.
- **Link Requirement**: User explicitly requires direct IBM documentation URLs in all diagnostic and troubleshooting answers for verification.
